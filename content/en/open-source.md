## Licences

| Part | Licence |
|---|---|
| Software and firmware | [Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0) |
| Hardware and enclosure | [CERN-OHL-S-2.0](https://ohwr.org/cern_ohl_s_v2.txt) |
| Documentation and photos | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) |

The licence of every file is recorded in the repository and checked with [REUSE](https://reuse.software/). The hardware is meant to be certified by the [Open Source Hardware Association](https://certification.oshwa.org/).

## Contribute

Ideas, bug reports and pull requests are welcome on [GitHub](https://github.com/padalton/doormutex). The README describes the project, its decisions and why they were made.

## Translate

English comes first, German is included. Adding your language takes JSON files for the web app and the desktop companion and a `.po` file for the KDE widget, no programming needed. See [TRANSLATING.md](https://github.com/padalton/doormutex/blob/main/TRANSLATING.md).

## This website

The [source of this website](https://github.com/padalton/doormutex-site) is open too: code under Apache-2.0, texts and images under CC BY-SA 4.0. The traffic-light icon and the screenshots come from the doormutex project. The site is static, runs no JavaScript, sets no cookies and loads nothing from other websites.

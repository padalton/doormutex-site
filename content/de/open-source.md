## Lizenzen

| Teil | Lizenz |
|---|---|
| Software und Firmware | [Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0) |
| Hardware und Gehäuse | [CERN-OHL-S-2.0](https://ohwr.org/cern_ohl_s_v2.txt) |
| Dokumentation und Fotos | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.de) |

Die Lizenz jeder Datei ist im Repository festgehalten und wird mit [REUSE](https://reuse.software/) geprüft. Die Hardware soll von der [Open Source Hardware Association](https://certification.oshwa.org/) zertifiziert werden.

## Mitmachen

Ideen, Fehlermeldungen und Pull Requests sind auf [GitHub](https://github.com/padalton/doormutex) willkommen. Das README beschreibt das Projekt, seine Entscheidungen und warum sie so gefallen sind.

## Übersetzen

Englisch zuerst, Deutsch ist dabei. Für deine Sprache brauchst du JSON-Dateien für Web-App und Desktop-Companion und eine `.po`-Datei für das KDE-Widget, ohne zu programmieren. Siehe [TRANSLATING.md](https://github.com/padalton/doormutex/blob/main/TRANSLATING.md).
